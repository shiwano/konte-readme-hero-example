# konte README hero

The [konte](https://github.com/shiwano/konte) workspace that produced the video at the top of konte's README. Everything under `videos/readme-hero/` was written and generated by a coding agent driving konte, with the human reviewing takes and leaving comments.

This is a dogfooding project, published as a reference for what a konte production looks like: the direction, the animatic and video stages, the adapters, the per-take state and the review records. It is not a template. The DSL it uses is a pre-release snapshot and will break; start a new piece with `konte init` instead of building on this one.

## Layout

- `videos/readme-hero/direction.ts` — beats, policy, rosters, setups
- `videos/readme-hero/reference.tsx`, `animatic.tsx`, `video.tsx` — the three production stages
- `videos/readme-hero/konte.state.json` — every take and its decision
- `videos/readme-hero/review/` — the agent's handoffs and the human's comments, per stage (written in Japanese)
- `videos/readme-hero/assets/` — generated takes referenced by the state
- `adapters/` — the ComfyUI and fal.ai adapters the piece uses
- `.agents/`, `.claude/`, `.codex/` — the skills and subagents konte installs into a workspace
