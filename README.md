# konte README hero example

The [konte](https://github.com/shiwano/konte) workspace that produced the video at the top of konte's README. Everything under [videos/readme-hero/](videos/readme-hero/) was written and generated by a coding agent driving konte, with the human reviewing takes and leaving comments.

This is a dogfooding project, published as a reference for what a konte production looks like: the direction, the animatic and video stages, the adapters, the per-take state and the review records. It is not a template. The DSL it uses is a pre-release snapshot and will break; start a new piece with `konte init` instead of building on this one.

Note that the direction was conducted in Japanese.

## Layout

- [videos/readme-hero/direction.ts](videos/readme-hero/direction.ts) — beats, policy, rosters, setups
- [videos/readme-hero/reference.tsx](videos/readme-hero/reference.tsx), [animatic.tsx](videos/readme-hero/animatic.tsx), [video.tsx](videos/readme-hero/video.tsx) — the three production stages
- [videos/readme-hero/konte.state.json](videos/readme-hero/konte.state.json) — every take and its decision
- [videos/readme-hero/review/](videos/readme-hero/review/) — the agent's handoffs and the human's comments, per stage (written in Japanese)
- [videos/readme-hero/assets/](videos/readme-hero/assets/) — generated takes referenced by the state
- [adapters/](adapters/) — the ComfyUI and fal.ai adapters the piece uses
- [.agents/](.agents/), [.claude/](.claude/), [.codex/](.codex/) — the skills and subagents konte installs into a workspace
